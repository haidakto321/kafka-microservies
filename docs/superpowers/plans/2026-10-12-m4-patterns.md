# M4 - Microservice patterns + observability: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an API gateway with an access-log filter, protect the order -> inventory REST call with Resilience4j (timeout, retry, circuit breaker, fast 503), and make the system observable - traces in Jaeger (including across the outbox), metrics in Prometheus, a Grafana dashboard - then run E8 and E9 and write them up for a beginner.

**Architecture:** A new `api-gateway` (Spring Cloud Gateway, reactive) routes `/api/orders/**` and `/api/products/**`. `ProductClient` gets `@Retry` (outside) + `@CircuitBreaker` (inside) with a 2 s timeout and a fallback that throws a 503. Every service gets Micrometer Tracing with the OpenTelemetry bridge (OTLP to Jaeger) and the Prometheus registry; Kafka observation is switched on so the trace id travels in Kafka headers. The outbox stores the W3C `traceparent` when a row is written and the relay continues that trace when it sends the row. A custom gauge exposes the number of unsent outbox rows. Jaeger, Prometheus and Grafana run in Docker Compose; Grafana is provisioned with a data source and a dashboard.

**Tech Stack:** Java 21, Spring Boot 3.5.6, Spring Cloud 2025.0.3 (Gateway 4.3.5), Resilience4j 2.4.0, Micrometer Tracing + OpenTelemetry (OTLP), Micrometer Prometheus registry, `jaegertracing/jaeger:2.21.0`, `prom/prometheus:v3.14.0`, `grafana/grafana:12.4.11`.

## Decisions this plan makes (not spelled out in the spec)

1. **Versions:** Spring Cloud **2025.0.3** (the line for Boot 3.5; released 2026-06-11), Resilience4j **2.4.0** (2026-03-14), images `jaegertracing/jaeger:2.21.0`, `prom/prometheus:v3.14.0`, `grafana/grafana:12.4.11` (all at least 2 weeks old; pulled through `mirror.gcr.io`, digests checked against Docker Hub - same workaround as M1).
2. **Gateway artifact `spring-cloud-starter-gateway-server-webflux`** (the 4.3 name; the old `spring-cloud-starter-gateway` is deprecated) and routes under `spring.cloud.gateway.server.webflux.routes`.
3. **Aspect order = Resilience4j's default: Retry outside the circuit breaker**, so every attempt is counted by the breaker (spec 7.2). The fallback is on `@Retry` (the outer one): a fallback on the inner `@CircuitBreaker` would turn the error into a 503 before Retry sees it, and nothing would be retried.
4. **Retry and breaker count only real outages**: `ResourceAccessException` (connection refused, timeout) and `HttpServerErrorException` (5xx). A 404 is an answer - not retried, not counted, still a 400 "Product not found" for the client.
5. **`minimum-number-of-calls: 10`** (Resilience4j's default is 100, so a 10-call window would never open in a demo). With 3 attempts per request, about 4 failed requests open the breaker.
6. **The timeout is set on the RestClient** through a `RestClientCustomizer` (2 s connect + read), not in `ProductClient`, so the existing `MockRestServiceServer` unit test keeps working.
7. **Outbox trace context lives in one small class per service, `OutboxTracing`**: it reads the current `traceparent` when a row is written and starts a "outbox publish" span from the stored one when the relay sends it. With Kafka template observation on, the producer span is a child of that span and the trace continues in the Kafka headers.
8. **Trace export endpoint `http://localhost:4318/v1/traces`** (Jaeger's OTLP/HTTP port), sampling 100%. Tests keep Spring Boot's default (tracing off) except the one outbox tracing test, which turns it on with `@AutoConfigureObservability`.
9. **The outbox gauge is unit-tested with a mocked repository** (the relay empties the table within 500 ms, so a live count is not deterministic); its Prometheus export is checked against the running system.
10. **Prometheus labels services by `job`** (one scrape job per service), so no extra metric tags are needed; HTTP histograms are switched on (`percentiles-histogram`) for the p95 panel.
11. **`e2e-check.ps1` now goes through the gateway** (`http://localhost:8080/api`), so the check also covers the gateway.

## Review Focus

1. **Inventory down or slow** - `POST /orders` answers 503 "Product service unavailable, try again" (after 3 attempts, within about 3 x 2 s), never 500, and saves nothing. Pinned by `a5xxIsRetriedThenBecomes503`, `aSlowInventoryTimesOut`, `inventoryDownMeansA503AndNoOrder` (Task 2) and E8.
2. **The breaker is open** - calls fail fast without touching inventory, and recover through half-open. Pinned by `theBreakerOpensAndThenFailsFast` (Task 2) and E8.
3. **A 404 from inventory** - stays a 400 "Product 99 not found", is not retried and does not open the breaker. Pinned by `a404IsNotRetriedAndStaysProductNotFound` (Task 2).
4. **A trace crosses the outbox** - the Kafka record sent later by the relay carries the same trace id as the request that wrote the row. Pinned by `theOutboxRowCarriesTheTraceAndTheKafkaRecordContinuesIt` (Task 5) and E9.
5. **Gateway paths** - `/api/orders/...` reaches order-service as `/orders/...`, unknown paths are 404, and every request is logged once. Pinned by the `ApiGatewayTest` tests (Task 3).

`product/ProductClient.java` (whole file):

```java
package com.kafkademo.order.product;

import io.github.resilience4j.circuitbreaker.annotation.CircuitBreaker;
import io.github.resilience4j.retry.annotation.Retry;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.http.HttpStatus;
import org.springframework.stereotype.Component;
import org.springframework.web.client.RestClient;

/**
 * Synchronous REST call to inventory-service for the product price, protected by Resilience4j (spec 7.2):
 * timeout 2 s (RestClient, see AppConfig), up to 3 attempts, and a circuit breaker.
 * Order of the aspects: Retry( CircuitBreaker( call ) ) - every attempt is counted by the breaker.
 */
@Component
public class ProductClient {

    static final String INVENTORY = "inventory";

    private final RestClient restClient;

    public ProductClient(RestClient.Builder builder, @Value("${inventory.base-url}") String baseUrl) {
        this.restClient = builder.baseUrl(baseUrl).build();
    }

    @Retry(name = INVENTORY, fallbackMethod = "unavailable")
    @CircuitBreaker(name = INVENTORY)
    public ProductInfo getProduct(long productId) {
        return restClient.get()
                .uri("/products/{id}", productId)
                .retrieve()
                .onStatus(status -> status.isSameCodeAs(HttpStatus.NOT_FOUND), (request, response) -> {
                    throw new ProductNotFoundException(productId);
                })
                .body(ProductInfo.class);
    }

    /**
     * Called after the last failed attempt, or at once when the breaker is open. Fail fast with a 503 -
     * never guess a price. A 404 is an answer, not an outage, so it is passed on unchanged.
     */
    private ProductInfo unavailable(long productId, Throwable cause) {
        if (cause instanceof ProductNotFoundException notFound) {
            throw notFound;
        }
        throw new ProductServiceUnavailableException(cause);
    }
}
```

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.cloud.gateway.filter.GatewayFilterChain;
import org.springframework.cloud.gateway.filter.GlobalFilter;
import org.springframework.core.Ordered;
import org.springframework.http.HttpStatusCode;
import org.springframework.http.server.reactive.ServerHttpRequest;
import org.springframework.stereotype.Component;
import org.springframework.web.server.ServerWebExchange;
import reactor.core.publisher.Mono;

/**
 * Spec 7.1: one log line per request - method, path, status and duration. A GlobalFilter runs for every route.
 * Reactive: chain.filter(...) returns at once; doFinally runs when the response is complete.
 */
@Component
public class AccessLogFilter implements GlobalFilter, Ordered {

    private static final Logger log = LoggerFactory.getLogger(AccessLogFilter.class);

    @Override
    public Mono<Void> filter(ServerWebExchange exchange, GatewayFilterChain chain) {
        long start = System.nanoTime();
        ServerHttpRequest request = exchange.getRequest(); // the original request, before StripPrefix
        return chain.filter(exchange).doFinally(signal -> {
            HttpStatusCode status = exchange.getResponse().getStatusCode();
            log.info("{} {} -> {} in {} ms", request.getMethod(), request.getURI().getRawPath(),
                    status == null ? "-" : status.value(), (System.nanoTime() - start) / 1_000_000);
        });
    }

    /** First filter in, last out - so the duration covers everything the gateway does. */
    @Override
    public int getOrder() {
        return Ordered.HIGHEST_PRECEDENCE;
    }
}
```

```java
package com.kafkademo.order.outbox;

import io.micrometer.tracing.Span;
import io.micrometer.tracing.TraceContext;
import io.micrometer.tracing.Tracer;
import io.micrometer.tracing.propagation.Propagator;
import java.util.HashMap;
import java.util.Map;
import org.springframework.beans.factory.ObjectProvider;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Component;

/**
 * The outbox breaks the trace on its own: the row is sent later, by another thread (spec 7.3). This class keeps it:
 * when a row is written it stores the current W3C "traceparent"; when the relay sends the row it starts a span
 * from the stored value, and the Kafka producer (observation on) continues the trace in the record headers.
 */
@Component
public class OutboxTracing {

    private static final String TRACEPARENT = "traceparent";

    private final Tracer tracer;
    private final Propagator propagator; // null when tracing is not set up (e.g. in most tests)

    @Autowired
    public OutboxTracing(ObjectProvider<Tracer> tracer, ObjectProvider<Propagator> propagator) {
        this(tracer.getIfAvailable(() -> Tracer.NOOP), propagator.getIfAvailable());
    }

    OutboxTracing(Tracer tracer, Propagator propagator) {
        this.tracer = tracer;
        this.propagator = propagator;
    }

    /** For unit tests: no tracing at all. */
    public static OutboxTracing none() {
        return new OutboxTracing(Tracer.NOOP, null);
    }

    /** The current span as a W3C traceparent, or null when nothing is being traced. */
    public String currentTraceParent() {
        TraceContext context = tracer.currentTraceContext().context();
        if (context == null || propagator == null) {
            return null;
        }
        Map<String, String> carrier = new HashMap<>();
        propagator.inject(context, carrier, Map::put);
        return carrier.get(TRACEPARENT);
    }

    /** A span for sending one row: a child of the stored trace if there is one, else a new trace. */
    public Span startPublishSpan(OutboxEvent event) {
        String name = "outbox publish " + event.getType();
        if (event.getTraceParent() != null && propagator != null) {
            return propagator.extract(Map.of(TRACEPARENT, event.getTraceParent()), Map::get).name(name).start();
        }
        return tracer.nextSpan().name(name).start();
    }

    /** Makes the span current, so the Kafka producer's span becomes its child. */
    public Tracer.SpanInScope inScope(Span span) {
        return tracer.withSpan(span);
    }
}
```

```java
    private boolean send(OutboxEvent event) {
        MessageEnvelope envelope = codec.envelope(event.getId(), event.getType(), event.getAggregateId(),
                event.getCreatedAt(), event.getPayload());
        Span span = tracing.startPublishSpan(event);
        try (Tracer.SpanInScope scope = tracing.inScope(span)) {
            // .get(...) waits for the broker to confirm the write (acks=all).
            kafka.send(event.getTopic(), event.getAggregateId().toString(), codec.toJson(envelope))
                    .get(10, TimeUnit.SECONDS);
            return true;
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            return false;
        } catch (ExecutionException | TimeoutException | RuntimeException e) {
            // RuntimeException: the producer can also throw directly instead of failing the future.
            // toString(), not getMessage(): a TimeoutException has no message and would log "null".
            log.warn("Outbox relay: could not send {} {} for order {} - will try again: {}",
                    event.getType(), event.getId(), event.getAggregateId(), e.toString());
            span.error(e);
            return false;
        } finally {
            span.end();
        }
    }
```
